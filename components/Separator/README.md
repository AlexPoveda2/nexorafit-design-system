# Separator

Línea divisoria de 1 px en `border` (Radix `Separator`).

- **Estado:** Shipped · `nexora-fit/src/shared/ui/separator.tsx` · [vista previa](../../visor/c/Separator.html)
- **Props:** `orientation` (`horizontal` por defecto · `vertical`), `decorative` (`true` por defecto: sin rol para lectores de pantalla).
- Usar `decorative={false}` solo cuando separa grupos que el lector de pantalla debe distinguir.
- **No:** separadores como único borde de un control, líneas de 2 px, `<hr>` con colores propios.
